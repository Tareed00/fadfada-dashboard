# 🎙️ مترجم فدفدة الفوري — Live Caption Translator

أداة ترجمة صوتية **فورية** من الإنجليزية (ولغات أخرى) إلى **العربية**، تعرض النص المترجم ككابشن احترافي على الشاشة لحظياً، مع خيارات عرض وتخصيص كاملة. تعمل مباشرة في المتصفح بدون أي خطوة بناء، ويمكن رفعها على أي استضافة مجانية، كما تتوفّر بنسخة **إضافة متصفح (Chrome Extension)**.

---

## ✨ المميزات

- **ترجمة فورية** للكلام إلى كابشن عربي يظهر على الشاشة لحظة بلحظة.
- **مصدران للصوت:**
  - 🎤 **المايكروفون** (داخلي/خارجي) — يعمل **مجاناً بالكامل** عبر محرك المتصفح (Web Speech API).
  - 🖥️ **صوت التبويب/النظام** (يوتيوب، اجتماعات، أي فيديو مفتوح) — عبر تفريغ Whisper (يتطلب مفتاح OpenAI).
- **محرّكان للترجمة:**
  - **مجاني** افتراضياً (Google غير الرسمي + MyMemory كاحتياط).
  - **احترافي** عبر مفتاح OpenAI لجودة وفصاحة أعلى.
- **خيارات عرض كاملة:** حجم الخط، لون النص، لون وشفافية الخلفية، موضع الكابشن (أعلى/وسط/أسفل)، إظهار النص الأصلي مع الترجمة، تمرير تلقائي، **وضع ملء الشاشة**.
- **لوحة إضافية** قابلة للتخصيص (الوقت المنقضي، عدد الكلمات، المحرك المستخدم، ملاحظات) — كأنها إضافة بجانب الترجمة.
- **تصدير** السجل كملف نصي `.txt` أو ملف ترجمة `.srt`.
- حفظ جميع التفضيلات والمفتاح **محلياً** في المتصفح (localStorage).
- مظهر داكن/فاتح، وواجهة عربية كاملة (RTL).

---

## 🚀 التشغيل المحلي

لا تحتاج أي تثبيت. فقط افتح `index.html` في متصفح حديث (يُفضّل **Google Chrome**).

> للحصول على إذن المايك وميزات الصوت، يجب فتح الصفحة عبر `https://` أو `http://localhost`
> (لن تعمل الأذونات عند فتح الملف بنقرة مزدوجة `file://`).

تشغيل خادم محلي سريع:

```bash
cd live-translator
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

## ☁️ الرفع على استضافة مجانية

ارفع محتويات مجلد `live-translator/` كما هي:

### GitHub Pages
1. ادفع الملفات إلى مستودعك.
2. Settings → Pages → اختر الفرع والمجلد `/live-translator`.
3. سيُعطيك رابطاً عاماً يعمل عبر HTTPS.

### Netlify / Vercel / Cloudflare Pages
- اسحب وأفلت مجلد `live-translator` في Netlify Drop، أو اربط المستودع في Vercel/Cloudflare.
- لا حاجة لأي أمر بناء (Static site).

---

## 🧩 تثبيت نسخة الإضافة (Chrome Extension)

1. افتح `chrome://extensions`.
2. فعّل **وضع المطوّر (Developer mode)**.
3. اضغط **تحميل غير مُحزَّمة (Load unpacked)** واختر مجلد `live-translator/extension`.
4. اضغط أيقونة الإضافة لفتح الأداة في **اللوحة الجانبية (Side Panel)**.

---

## ⚙️ الإعدادات (مفتاح API)

- افتح ⚙️ الإعدادات وأدخل **مفتاح OpenAI** لتفعيل:
  - الترجمة الاحترافية الفصيحة.
  - تفريغ صوت التبويب/النظام (Whisper).
- المفتاح يُحفظ في متصفحك فقط ويُرسل **مباشرة** إلى OpenAI، ولا يمر بأي خادم وسيط.

> ملاحظة أمنية: لأن الأداة تعمل من المتصفح مباشرة، فإن المفتاح يكون مكشوفاً لمن يستخدم نفس الجهاز/المتصفح. استخدم مفتاحاً مخصصاً بحدود إنفاق إن أمكن.

---

## 📌 ملاحظات تقنية

- **لماذا صوت التبويب يحتاج مفتاحاً؟** المتصفحات لا تسمح بتمرير صوت ملتقط من التبويب/النظام إلى محرك التعرّف المجاني المدمج، لذلك يُرسل الصوت على شكل مقاطع كل ~4 ثوانٍ إلى Whisper للتفريغ ثم يُترجم.
- **أفضل دعم:** Google Chrome على سطح المكتب. التعرّف المجاني على الكلام غير مدعوم في بعض المتصفحات.
- عند مشاركة الشاشة/التبويب، احرص على تفعيل خيار **«مشاركة صوت التبويب/النظام»** في نافذة المتصفح.
